# 01. 5 分钟体验：你的第一个 CLI Agent 任务

> 目标：**复制粘贴就能跑通**，不解释原理，只建立"它能干活"的信心。

---

## 0. 启动前检查（30 秒）

在开始前，请确认：

| 检查项 | 命令/操作 | 预期结果 |
|-------|----------|---------|
| Python 版本 | `python --version` | 3.10 或更高 |
| 依赖安装 | `pip list \| grep -E "openai\|duckduckgo"` | 显示已安装 |
| API Key | `$env:MOONSHOT_API_KEY` (PowerShell) | 显示你的 key |

如果还没准备好，先回到环境配置章节完成设置。

---

## 1. 启动 Mini Kimi（30 秒）

**Windows (PowerShell):**
```powershell
$env:PYTHONPATH="mini_kimi/src"
python mini_kimi/src/mini_kimi/ui/shell/main.py
```

**成功标志：** 看到下面的欢迎语，光标停在 `User>` 后面等待输入

```
Welcome to Mini Kimi CLI (Refactored)!
Type 'exit' or 'quit' to leave.

User> _
```

---

## 2. 第一条命令：让它自我介绍（1 分钟）

直接复制粘贴这句话：

```
你好，请介绍一下你自己，并列出你能使用的工具。
```

**你应该看到：**
1. 先出现 `[Thinking...]` - 表示正在思考
2. 然后出现 Kimi 的回复，告诉你它有哪些工具（Bash、WriteFile、SearchWeb、FetchURL）

```
Kimi: 我是 Kimi，一个运行在 Windows 10 上的 CLI 助手。我可以使用以下工具：
- Bash: 执行 Shell 命令
- WriteFile: 写入文件
- SearchWeb: 联网搜索
- FetchURL: 读取网页内容
```

✅ ** Checkpoint 1 通过！** 说明 CLI 能正常对话。

---

## 3. 第一条工具调用：探索当前目录（1 分钟）

复制粘贴：

```
请用 Bash 工具查看当前目录下有哪些文件和文件夹
```

**你应该看到：**

```
[Thinking...]
[Tool Call] Bash({"command": "ls -la"})
[Tool Result] {"stdout": "total 128\ndrwxr-xr-x  6 user..."}...

Kimi: 当前目录包含以下内容：
- docs/ - 文档目录
- mini_kimi/ - 源代码目录
- README.md - 项目说明
...
```

✅ ** Checkpoint 2 通过！** 说明工具调用链路正常。

---

## 4. 第一个实用任务：创建文件（2 分钟）

复制粘贴：

```
请在当前目录创建一个名为 hello.txt 的文件，内容为 "Hello from Mini Kimi!"，然后读取确认内容正确。
```

**你应该看到：**

```
[Thinking...]
[Tool Call] WriteFile({"path": "hello.txt", "content": "Hello from Mini Kimi!"})
[Tool Result] {"stdout": "File written successfully", ...}...
[Thinking...]
[Tool Call] Bash({"command": "cat hello.txt"})
[Tool Result] {"stdout": "Hello from Mini Kimi!", ...}...

Kimi: 已成功创建 hello.txt 文件，内容为 "Hello from Mini Kimi!"，读取确认无误。
```

去你的文件管理器查看，应该能看到 `hello.txt` 文件！

✅ ** Checkpoint 3 通过！** 说明文件操作工具正常。

---

## 5. 联网搜索体验（2 分钟）

复制粘贴：

```
搜索 "Python 3.13 新特性"，并总结最重要的 3 个变化
```

**你应该看到：**

```
[Thinking...]
[Tool Call] SearchWeb({"query": "Python 3.13 新特性"})
[Tool Result] [{"title": "What's New In Python 3.13", ...}]...

Kimi: 根据搜索结果，Python 3.13 最重要的 3 个新特性是：
1. ...
2. ...
3. ...
```

✅ ** Checkpoint 4 通过！** 说明联网搜索功能正常。

---

## 6. 观察重点：Agent 的工作方式

完成上面 4 个任务后，你应该已经注意到 Mini Kimi 的工作模式：

```
你提需求 → [Thinking...] → 可能调用工具 → 观察结果 → 给你回答
```

**关键观察点：**

| 现象 | 含义 |
|-----|------|
| `[Thinking...]` | Agent 正在分析你的需求 |
| `[Tool Call] xxx` | Agent 决定使用工具来解决问题 |
| `[Tool Result] xxx` | 工具返回的结果 |
| `Kimi: xxx` | Agent 基于观察给出最终回答 |

这就是 **ReAct 循环**：思考 → 行动 → 观察 → 回答

## 你现在应该建立的直觉

1. **Mini Kimi 不只是聊天** - 它会主动使用工具来完成任务
2. **过程可见** - 你能看到它什么时候在思考、什么时候在调用工具
3. **结果可验证** - 文件真的在磁盘上、搜索真的能联网

这些特性让 Mini Kimi 成为一个"能干活的工程搭档"，而不只是一个"会说话的聊天机器人"。
